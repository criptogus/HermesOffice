# Templates

Ready-to-use starting points for documents and decks. They are written in
English and designed **for AI agents first**: every placeholder is
`[bracketed]`, every section carries a one-line guidance note the agent
replaces with real content, and each deck spec maps directly onto the
arguments of the slides agent's `plan_deck`/`generate_deck` tools.

## Layout

- `docs/` — eight `.docx` templates, generated by
  `npm run templates -w @hermesoffice/docx-engine` (edit
  `packages/docx-engine/scripts/generate-templates.ts` and regenerate; don't
  hand-edit the binaries):
  - `meeting-notes.docx` — agenda, discussion, decisions, action-item table
  - `idea-brief.docx` — one-sentence idea, problem, solution, next experiment
  - `business-plan.docx` — exec summary through financials and the ask
  - `project-proposal.docx` — goals/metrics, scope, milestones, risks
  - `status-report.docx` — TL;DR, done/planned, blockers, metric trends
  - `product-requirements.docx` — PRD: stories, requirements table, rollout
  - `decision-memo.docx` — options table, recommendation, decision record
  - `one-pager.docx` — single-page executive summary with a clear ask
- `decks/` — eight deck style specs (`.md`) for the slides agent: `modern`,
  `elegant`, `professional`, `keynote-speaker`, `minimal`, `tech-dark`,
  `investor-pitch`, `workshop`. Each contains a **Style** section (passed
  verbatim as `generate_deck`'s `style`) and a **Suggested page plan**
  (adapted into `pages`).
- `deck-*.pptx` — theme base decks kept from upstream.

## How agents should use these

**Documents (docs app or headless):** open the `.docx` template, replace
every `[placeholder]` and italic guidance line with real content, keep the
heading structure, and remove the template note before delivering.

**Decks (slides app):** read the chosen spec in `decks/`, call `plan_deck`
with the user's content mapped onto the suggested page plan, then
`generate_deck` passing the spec's Style section as `style`. Figures always
require a declared `dataSource`; sample data must be flagged to the user.
